## Sole active choice

EP-D02-C3c.2 chooses only the root system's primary gameplay job:

- **A, recommended — cross-source build weaver:** useful output requires a
  relationship among multiple independently legal and already-accounted action
  or build sources; Charms customize the relationship. It cannot change the
  source records or let one effect trigger another effect.
- **B — self-contained tactical engine:** the Relic supplies a complete combat
  loop even without behavior-bearing gear; Charms tune that loop.
- **C — mastery covenant:** the Relic declares a visible optional performance
  condition and only satisfying it enables the later payoff; Charms customize
  the covenant grammar.

seventeenth pseudo-item. Its cost is combinatorial testing and a set-bonus
failure mode that could favor rigid recipes or dense Legendary kits. For an
illustrative A boundary, a `guard` source and a `fire` source may make the
player-executed `guard -> fire` relationship meaningful, but either source alone
has no cross-source payoff and the first effect never fires the second.
