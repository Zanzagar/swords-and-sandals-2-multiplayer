equal-`u`, unequal-`U` pair. At the tight floor, Ashen's existing morphic pair
carries the rule, so Slate need not exist:

```text

ASHEN rotates       • A1/A2
VEIL anchors        • V1
```

If Slate is later authored with capable geometry, it must receive some actual
alternate such as `S2 U={a,c},u=2`. B turns structural capability into a
reliable named dialect, avoids a support-only subtype, and prevents one
showcase definition from carrying C86-A while other capable names stay latent.
Its tight floor remains five
definitions, seven keys, and forty-two rows.

capable definition, plus the risk that this class looks like a premium tier

existential per definition: it does not require every exact key or every pair
inside a definition to rotate.
