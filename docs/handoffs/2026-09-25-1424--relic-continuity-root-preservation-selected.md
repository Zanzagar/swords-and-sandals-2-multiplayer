selected root-coarsening and applicable relation-promotion rules. A multi-root
basis qualifies only when:

- every member currently supports the same fact, rather than appearing only in
  ancestry, provenance, an earlier cut, or co-presence;
- distinct members have disjoint complete lineages, no ancestor relation, and
  no shared nonmultiplying authorization/accounting parent;

  non-support input fixed while removing any one member changes the fact's

root with multi-parent ancestry is one member and cannot count beside an

both are present. A revision cause in the preserved continuity root's ancestry
