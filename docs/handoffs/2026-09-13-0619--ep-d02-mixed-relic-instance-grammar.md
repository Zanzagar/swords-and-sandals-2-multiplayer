## Selected direction

Let `D+` be supported Relic definitions participating in reachable, materially
functional final entries in `E+`. C3c.39-C requires `V_R`, the within-cell
instance-variable subset, to be nonempty and proper:

- at least one materially participating definition outside `V_R` must be
  invariant under every legal same-definition instance substitution within
  every temporal-by-basis cell in which it participates; and
- at least one distinct definition in `V_R` needs a reachable material witness
  comparing two actor-ID-preserving alternate legal worlds for the same
  combatant, each containing exactly one same-definition instance, while every
  other semantic input and the cell remain fixed.

The alternate instances never coexist, so the witness does not reopen the
one-per-definition personal collection rule. A changed instance ID, provenance
label, history, or cosmetic without a predicate-result difference does not
count. A difference realized only by changing temporal or basis cell does not
count for C3c.39.

The first card presentation recommended universal definition stability. After
the owner's follow-up, the recommendation changed openly to C: stable Relics can
anchor and teach the system while a deliberately exceptional variable class
can create personal artifact stories and different build puzzles. The fun
target is qualitative individuality, not hidden superior/inferior rolls.

That rationale does not yet select a variable-class ratio or definition list,
named facets, generation, disclosure, preview, choice, reroll, re-attunement,
sidegrade/non-domination rule, power bound, or bad-outcome protection. Each
remains a later atomic decision. Cross-cell and payoff instance variation also
remain open. C3c.39-C is a direction rather than an accepted EP-D02 replacement
and changes no authoritative wording.

## Sole active choice

C3c.4-C guarantees a nonempty set `I` of materially functional input-Charm
definitions. Let `I_E` contain those definitions with at least one reachable,
material active use in the already-selected six-cell `E+` domain. Participation
is extensional: while holding the exact Relic instance/state, Bound Soul,
payoff Charm, qualifying sources, version, and every other semantic fact fixed,
the two reachable legal worlds—one with that exact Charm instance active and
one with the input lane empty—must make the final predicate return different
results. A label or inert equipped Charm does not count.

- **A — neutral-only catalog:** `I_E` is empty. Every functional input-Charm
  definition works only through basis-neutral `E0` entries. This disconnects
  input Charms from all six action/build cells and necessarily creates
  materially charmed neutral content.
- **B, recommended — every definition participates in `E+`:** `I_E=I`. Every
  functional input-Charm definition has at least one material use in the six-
  cell system. A definition may also have neutral uses; B neither requires nor
  forbids them. This anchors every named Charm to a legible action/build recipe
  without prematurely closing off neutral experimentation.
- **C — mixed participation:** `I_E` is a nonempty proper subset of `I`, so at
  least two definitions exist: at least one has an `E+` use, and at least one
  distinct functional definition is neutral-only. `I_E` members may also have
  neutral uses. This creates recipe-linked and basis-neutral Charm roles,
  with the cost of two catalog languages and greater mapping/UI complexity.

A/B/C exhaust empty/all/nonempty-proper `I_E`. Exact cells, definition counts,
neutral use under B, identity mapping, definition-versus-instance sensitivity,
cross-cell variation, payoff-side sensitivity, base-grammar ownership,
transformations/precedence, content, power, acquisition, horizons,
persistence, validation, and release remain open. After B/C, the later `E+`
instance-sensitivity domain is guaranteed nonempty. After A, that question
routes through `E0`.
