## Sole active choice

Let `P_v=R_v* x S_v=E_v`, the nonempty pair product selected through C3c.49-A.
Let `F_v` contain `(b,s)`, for tagged `b=(d,r)`, only when one legal fixed
context holds definition, exact realization, owner, version, Soul, boundary,
one exact source configuration, and one exact payoff-Charm state or empty lane
fixed; contains zero active input-type Charm instances; and reaches
`|a_h(y)|=2` in one final-input state.

Empty means no active input Charm, not a null, no-op, extensionally neutral, or
merely inactive owned Charm. Receipts cannot be combined across contexts,
Souls, sources, or times. A pair is outside `F_v` only after complete analysis
of every legal empty-input context and reachable state proves width at most
one. Zero input Charms keeps the root configuration permitted, but each
proposed source context must still satisfy every other rule. Failure to find a
witness is unresolved. C3c.49-A then derives an active-input-Charm dual witness
for every true nonmember.

- **A, recommended — universal input-Charm-free dual access:** `F_v=P_v`.
  Every Soul/operative-realization pair has some catalog dual route with its
  input lane empty. Input Charms may still change or add routes, and C3c.40-B
  still requires every functional input-Charm definition to matter somewhere
  in `E+`. The cost is a full empty-lane authoring/validation matrix, less room
  for Charms to unlock genuinely new dual access, and redundancy or automatic-
  fill risk if their eventual content is poorly authored.
- **B — mixed native and input-Charm-dependent pairs:** `F_v` is a nonempty
  proper subset of `P_v`. Some exact pairs dual empty-lane; others require an
  input Charm for every dual route. This can create exciting bridge Charms, but
  also a hidden premium native class while acquisition, disclosure,
  compensation, and mapping stability remain unselected. B leaves its Soul and
  realization projections for separate later choices.
- **C — universal input-Charm requirement for dual:** `F_v` is empty. Every
  pair's C3c.49-A dual witness uses an active input Charm. This gives the Charm
  lane a clear structural job but turns a logically optional personal item into
  a soft requirement for the flagship two-result grammar before its acquisition
  is guaranteed. Empty-lane play remains legal and may be focused or silent.
