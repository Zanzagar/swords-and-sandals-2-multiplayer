## Sole active choice

For exact pair `p`, define

`I_v(p)={c in C6 : some legal empty-input dual context anchored to p has a valid local grounding package T={c}}`

and

`U_v={p in P_v : I_v(p) is nonempty}`.

A singleton package means the exact same-context receipt-occurrence transition
has an inclusion-minimal semantic predicate package whose cell projection is
one cell. The package may still contain several outputs inside that cell, use
several sources, and be difficult to reach. It establishes cell-level causal
attribution, not player control, easy triggering, one predicate, one source,
one receipt, or one simple route.

- **A, recommended — every pair has an independent foothold:** `U_v=P_v`.
  Every pair has at least one singleton cell-grounding witness, while other
  routes and cells may remain genuinely coupled. This supplies one attributable
  anchor that later teaching and feedback can explain. Its cost is one real
  singleton witness per pair, authoring and validation load, token-anchor
  pressure, and the risk that later tuning makes the anchor an automatic easy
  route. A alone does not promise that ease.
- **B — some pairs have footholds; others are coupled-only:** `U_v` is a
  nonempty proper subset. At least one pair has a singleton witness, while at
  least one other pair has only packages of size two or more. This can create a
  special coupled-only mastery class, but also a hidden explanation-complexity
  class that needs its complete coupled dependency disclosed and taught.
- **C — every pair is coupled-only:** `U_v` is empty. Every valid six-cell-
  grounded native-dual foothold uses two or more cells. C3c.52-B prevents
  vacuity, so every pair still has a package and C derives
  `|C_v(p)|>=2` for every pair. This makes the selected surface wholly cross-
  cell coupled and may support exciting mastery puzzles, but removes
  independent cell attribution everywhere. Non-six-cell receipt causes remain
  open.
