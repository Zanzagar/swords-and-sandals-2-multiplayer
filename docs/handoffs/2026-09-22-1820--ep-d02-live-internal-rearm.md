For each legal adjacent-commit witness `w`, let `D^{live}(w)` be the set of its

An opportunity `d` has **live-internal leverage**, `L^{live}(d)`, when a
reachable isolation pair satisfies all of these conditions:

1. later choices and exogenous/random inputs are held fixed except for the
   isolated legal alternatives;
2. fixed `h` remains operatively available in both arms at every authoritative

A transient exit and return before `tau` fails condition 2. Generic delay,
phase divergence, encounter termination, or global result unreachability is
insufficient. Later context loss remains legal. The actually chosen
continuation need not exercise the leverage.
