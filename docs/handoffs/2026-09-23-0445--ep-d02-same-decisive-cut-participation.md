Because the two qualifying pairs share one actual continuation, exact same-cut
equality fixes the actual arm to one completion status. Both counterfactual
arms must therefore have the opposite status: either the actual completes and
both counterfactuals do not, or the actual does not complete and both
counterfactuals do. A same-cut witness cannot have one marginal alternative
accelerate completion while the other delays it at that cut. This does not
merge the pairs or create one counterfactual world containing both changes.
