## Active owner choice — EP-D02-C3c.135

Reuse the nonempty tagged domain

`K^{candidate}_v = disjoint-union_{h in H+} {(h,j):j in J_h}`.

For each fixed tag, a semantic state is relationship-sufficient when the
authored relationship facts would yield `j` after projecting out bookkeeping
whose sole purpose is cooldown, prior-receipt consumption, retry suppression,
or recurrence gating. A **continuous-sufficiency interval** is a maximal
interval of one legal, nonforked combat history in which that relationship
remains sufficient after every authoritative semantic state transition. If the
fixed tag or context
becomes unavailable or terminates, that absence is relationship-insufficient
for any later rearm rather than a continuation of held truth.

A **distinct recommit** is a fresh, strictly later authoritative pre-payoff
commit of the same `j` inside one continuous-sufficiency interval whose
occurrence candidate is newly authorized only after the first commit. It remains
separately player/consumer-semantic; that temporal obligation is new in C135,
not something C44-A already guaranteed. A candidate already queued before the
first commit, delayed/duplicate settlement, callback duplication, polling,
logs, serialization, retry, rollback, reload, packet redelivery, replay, or
observing the first held result twice remain one occurrence.

Let `R^{hold}_v` contain exactly the tags for which one fully specified,
nonforked history—with participant choices and exogenous/random inputs fixed—
contains an initial commit and at least one distinct recommit inside one
continuous-sufficiency interval. Random divergence cannot manufacture
membership. Negative membership requires complete reachable-domain analysis.

### A — every relationship must break before it rearms — recommended

`R^{hold}_v` is empty. Every tag commits at most once per continuous-
sufficiency interval. A later same-tag commit requires an authoritative
relationship-insufficient state followed by renewed sufficiency. This gives
results crisp event boundaries and prevents persistent history/state truth from
becoming a polling-driven passive receipt engine. It still permits a later
persistent or channeled payoff from the first receipt; only fresh input receipts
require a break.

Cost: maintaining a difficult formation produces no second input result until it
breaks, and players may deliberately flicker a cheap condition. Later
requalification, cadence, and balance rules must address reset gaming. At the
same Soul/same Relic/same relationship across the post-commit interval, the
marginal rule is **neutral/protective**; the initial inherited source–Relic–
result relation may remain **direct**. Universal prevalence is **aggregate**.

### B — every tag can recommit while held true — strongest countercase

`R^{hold}_v=K^{candidate}_v`. Every tag has some fully specified continuous-
sufficiency interval with two distinct commits. This is a capability witness,
not a commit at every cut, an exact pulse interval, or infinite repetition. It
rewards maintaining a hard relationship rather than intentionally breaking it.

Cost: every receipt, including co-results, inherits channel-engine pressure;
cadence, caps, burst control, and UI become urgent. At the same-tag/continuous-
relationship/across-two-commit boundary, persistence and distinct genuine
manifestations coexist. Rate that **partial** until later cadence and
consumption rules make the distinction fully legible; universal prevalence is
**aggregate**.

### C — break-to-rearm and sustained-recommit tags coexist

`R^{hold}_v` is a nonempty proper subset of `K^{candidate}_v`. This supports
one-shot Vows beside sustained Echoes. Positive tags retain B's **partial** fit,
negative tags A's **neutral/protective** fit, and catalog coexistence is only
**aggregate**. Costs are two recurrence languages, greater disclosure/testing
burden, token witnesses, and likely premium status for repeat-capable forms.
