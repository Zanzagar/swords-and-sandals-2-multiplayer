## Corrected frontier

The first proposed next card would have jumped directly from “at least one
common pair” to “every pair changes every Soul.” A bounded adversarial
quantifier check caught a real coarser atom: C97-C allows extra exact keys that
belong to no common pair. Under the coarse-to-fine workflow, exact-key coverage
must be decided before graph completeness.

For each locked definition `d`, graph its completed exact keys `B_v(d)` and use
C97's set `W^S_v(d)` of all-Soul-changing pairs as edges. Let

`K^W_v(d)=union W^S_v(d)`

be the incident keys, and let

`D^{K-S}_{full,v}={d in D^{U=}_{locked,v} : K^W_v(d)=B_v(d)}`.

C97-C proves that every graph has at least one edge, not that every vertex is
incident. C96-A already derives `for every key and Soul, there exists a Soul-
dependent changing partner`. C98's genuinely new quantifier is `for every key,
there exists one partner that changes every Soul`. Every-pair/every-Soul
coverage is a stronger descendant, not a peer option.
